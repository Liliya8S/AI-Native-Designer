# Feature-gap анализ: Наш продукт vs Drom (кратко)

## Сводная таблица (MVP vs Drom)

| Функция | Наше MVP (приоритет) | Drom (текущее состояние) | Gap / Вывод |
|---|---:|---|---|
| Билеты и тесты | Полный оффлайн‑набор, адаптивные тесты (MVP core) | Сильный — большой набор билетов, оффлайн | Конкурентность: паритет; нужно лучше UX и retention‑фичи |
| Фото‑ассистент (распознавание знаков) | On‑device + cloud fallback, offline база, быстрый ответ ≤3s | В основном нет (фокус на тестах/контенте) | Большое окно для дифференциации — наше преимущество |
| On‑device ML (приватность, latency) | Да (quantized TFLite/CoreML, p95 <3s) | Нет / ограничено | Технологический moat — позиционировать как приватный и быстрый |
| Видео‑анализ / разбор ДТП/ситуаций | Планируется (премиум этап) | Вряд ли есть | Возможность премиум‑контента и удержания |
| Чат‑ассистент (вопросы ПДД) | Онлайн LLM + offline FAQ; голосовой ввод как опция | Нет (контент/портал) | Отличие в UX — conversational help ≈рост удержания |
| Gamification / прогресс | Да (бейджи, ежедневные задания) | Минимально | Повышает D1/D7 retention — важно для роста |
| Offline TTS / голосовые подсказки | Offline системный TTS; premium neural online | Маленькая вероятность наличия | Удобство для hands‑free обучения; маркет.фича |
| Map hotspots / локальный контент | План/опция (учебные зоны, штраф‑карты) | Нет | Нишевое преимущество для локальных водителей |
| AR‑функции во время вождения | Запрещено/ограничено (policy) — safety first | Нет явных AR‑навесок в Drom | Правильная безопасность как маркет.позиция |
| Монетизация / трафик | Freemium: тесты free, recognition/assistant premium; B2B для автошкол | Реклама + премиум; большой бренд/трафик | Drom сильнее по трафику; мы должны быстро доказать ценность премиума |

## Ключевые выводы
- Главная Drom‑сильная сторона — бренд, трафик и зрелый продукт по билетам. Это барьер по скорости набора аудитории.
- Нашы основные дифференциаторы: оффлайн photo‑assistant с on‑device ML (приватность + скорость), conversational assistant и геймификация.
- Быстрое MVP с тестами+фото‑ассистентом закроет «core» функционал и даст уникальное предложение против Drom.

## Рекомендации (быстрое действие)
1. Приоритет: выпустить MVP с полным набором билетов + on‑device photo‑assistant (offline). Это даёт моментальную дифференциацию и низкий порог доверия у пользователей.
2. Интегрировать распознавание в поток обучения: распознал знак → добавил в «ошибки» → включил в план повторения. Это повышает retention и ценность подписки.
3. Маркетинг: позиционировать приватность и скорость (on‑device) против «порталов». Запустить CPC/ASO кампанию на нишевые поисковые запросы по распознаванию знаков и экзаменам.
4. Дорожная карта: 0–3 мес — тесты + photo‑assistant; 3–6 мес — chat‑assistant (online LLM) + gamification; 6–12 мес — видео‑разборы и B2B для автошкол.
