# AI-Native Designer — ПДД Ассистент

Мобильное b2c edtech-приложение для подготовки к экзамену ПДД (автошкола).
Дизайн-система построена в Figma и один-в-один перенесена в React-код.

## Из чего состоит проект

- **`ds/`** — источник истины дизайн-системы: контракт (`CONTRACT.md`), токены и
  радиусы/отступы (`foundation.md`), каталог компонентов (`components.md`),
  композиция экранов (`screens/`). Оригинал — в Figma, ссылки внутри файлов.
- **`src/tokens/`** — те же токены, что в Figma Variables, зеркалом в CSS
  (`primitives.css` → `semantics.css`, двухслойная система).
- **`src/components/`** — React/TypeScript-реализация UI-кита: 24 компонента,
  один-в-один с Figma (имена, варианты, состояния).
- **`.storybook/`** — каталог компонентов: у каждого своя страница с контролами,
  всеми вариантами/состояниями, живыми переходами и Copy code (autodocs).
  Плюс `src/sandboxes/` — сборки компонентов в реальных композициях экрана
  (модалка, форма, навигация, лента с фидбеком, поток теста).
- **`directives/`** — SOP-инструкции, по которым построен проект (агентный
  workflow: Figma → React-база → Storybook → передача на GitHub).

## Как запустить

```bash
npm install

npm run dev              # приложение (Vite) — http://localhost:5173
npm run storybook        # каталог компонентов — http://localhost:6006
npm run build             # прод-сборка приложения
npm run build-storybook   # статическая сборка каталога
npm run lint               # oxlint
```

## Дизайн-система

Правила работы с UI (только токены, только компоненты из кита, Auto Layout
в Figma) — в [`ds/CONTRACT.md`](ds/CONTRACT.md). При любых изменениях дизайна
сначала синхронизируется Figma, затем — `ds/*.md` и React-код.
