# Scope MVP

## Одно предложение
Мобильное приложение для начинающих и после перерыва водителей: оффлайн‑тесты ПДД + photo‑assistant с голосовой подсказкой

## Список фич MVP (Must Have)
- Билеты и тесты (offline)
- Photo‑assistant (распознавание знаков)
- On‑device ML + offline DB
- Voice/TTS краткая сводка
- Confidence indicator + retry подсказка
- «Добавить в повторение» / карточки повторения
- История сканов (последние 5)
- Privacy badge / messaging
- Onboarding / first‑time quick tour
- Analytics events / instrumentation

## Основной сценарий (Primary persona — Игорь)
1. Установка и первый запуск → короткий онбординг (3 шага): показать `Start test`, `Camera`, `History`.
2. Быстрый чек перед поездкой: тап на виджет/открытие приложения → нажать `Камера` или использовать shortcut.
3. Навести камеру на знак → on‑device модель распознаёт (p95 <3s) → голосовая сводка (1‑2 предложения) + карточка с кратким описанием и индикатором confidence.
4. При низкой confidence — подсказка «повторите съёмку» + кнопка `Повторить` / `Подробнее`.
5. Пользователь может нажать `В повторение` для добавления в очередь, либо `Сохранить` для истории.
6. История доступна в профиле (последние 5 сканов), экспорт/поделиться для инструктора — опция в будущих версиях.

## Что осознанно НЕ входит (топ‑3 Should Have)
1. Widget / wake‑word / Bluetooth shortcut — удобство, но требует дополнительной разработки и прав на фоновые сервисы; добавить в v1.1.
2. Accident mode (full) — важная функция, но требует юридической и UX проработки; сделать в v1.1.
3. Video analysis / premium short breakdowns — высокие затраты на ML и контент; отложить до v2.

Причина: фокус на core JTBD — быстрое распознавание знаков и базовые тесты; остальные функции повысит retention и монетизацию позже.
