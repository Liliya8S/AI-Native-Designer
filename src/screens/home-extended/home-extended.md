  инструктору») — реальные иконки после расширения компонента пропом `icon`. Изначально у второй карточки была
  iconSide=right (совпадало с тогдашним макетом); пользователь позже обновила Figma — обе карточки теперь с
  иконкой слева — синхронизировано (см. «Обновление» ниже).
- `ScanRow` ×3 (category red/blue/neutral — neutral как ближайшее для жёлтого знака приоритета, отдельного цвета под жёлтый в ScanRow нет; thumbSrc — реальные фото знаков, см. «Фото» ниже)

## Локальные доменные блоки (`parts/`)
- `HeroCta` — тёмная CTA-карточка сканера (`surface-inverse`, полупрозрачный белый круг под иконку). Один экран — в базу не выносится.
- `NotificationBell` — колокольчик с индикатором непрочитанных (красная точка). Не `IconButton`: нет поверхности/фона, только иконка + бейдж.

## Общий каркас (`src/screens/shared/PhoneFrame`)
StatusBar/HomeIndicator — OS-хром Apple UI Kit, не часть продуктовой ДС (см. `ds/CONTRACT.md`), вынесен сразу в `shared/`, т.к. повторится на всех 9 экранах импорта. Упрощение относительно Figma: там `HomeIndicator` — абсолютный оверлей + отдельный `SafeAreaBottom`-спейсер (обход бага центрирования в Auto Layout); в CSS flexbox центрирование тривиально, поэтому в React это один элемент в потоке, не оверлей+спейсер.

## Прогресс-бар — не инстанс `ProgressBar`
В макете внутренний `LabelRow` компонента `ProgressBar` скрыт (`visible=false`), сверху и снизу — свой текст. Анатомия не совпадает с текущим API базового `ProgressBar` (нет пропа для скрытия лейбла, а редактировать базу при сборке экрана нельзя). Поэтому трек/заполнение собраны локально на токенах (`--surface-well` трек, `--bg-category-blue` заливка, `--radius-sm`), без инстанса компонента — как и было в исходной Figma-сборке.

## Типографика
Заголовок HeroCTA (Figma: Inter Semibold 18px) сведён к каноническому `ds-heading-lg` (18px, но medium — единственный существующий DS-стиль этого размера). Одноразовый semibold-18 не заводился, т.к. в ДС нет такого именованного стиля.

## Фото
Три превью в `ScanRow` (`src/assets/photos/scan-*.png`) — не сгенерированы через Higgsfield, а вытащены напрямую из Figma (`download_assets` → `rawImages`), т.к. в макете это уже реальные фото знаков, не пустые заглушки. Даунскейлены с исходных 2048×2048 до 192×192 (`sips`).

## Обновление 11а: логотип — текст на Unbounded вместо растрового PNG (дополняет устаревшее Обновление 2)
Обновление 2 (выше) описывает логотип как растровый PNG (`driver-logo.png`) + абсолютно позиционированный текст

## Обновление 18: кнопка-сканер по центру `TabBar` (общий компонент)
По референсу (скриншот таббара с приподнятой круглой кнопкой камеры по центру) добавлена отдельная кнопка

`camera-bold`, `onClick` ведёт на `/screens/camera-consent`. Несколько итераций размера: сначала 56px с
`margin-top: -28px` (сильно перекрывала контент над табаром, например кнопку «Записаться ещё» на экране записи
к инструктору) — уменьшена до 44px / `margin-top: -14px`; тень смягчена (`0 6px 18px rgba(17,17,18,0.14)`,
была резче и темнее). Общий компонент `src/screens/shared/TabBar` — эффект виден на всех экранах с таб-баром,
не только на главном. Только в прототипе, Figma не менялась.
