# Инвентаризация экранов

Источник: `directives/prd.md` (PRD — AI Native Driving Assistant v1.0).

## Экраны и состояния из PRD

| Имя (лат.) | Что происходит |
|---|---|
| Onboarding | Краткий тур при первом запуске: знакомит с тремя основными действиями — тест, камера, история |
| Home | Главный экран с CTA «Начать тест» / «Камера» / «История» |
| Tests | Каталог/список билетов ПДД, доступных оффлайн |
| TestSession | Прохождение билета: вопрос за вопросом, с оффлайн-доступом |
| TestResult | Разбор ответа сразу после вопроса: правильно/нет + кнопка «Добавить в повторение» |
| Camera | Экран камеры: наводишь на знак, идёт распознавание (on-device, p95 <3с) |
| RecognitionResult | Карточка результата: голосовая сводка 1–2 предложения, индикатор уверенности модели (High/Medium/Low), кнопки «Повторить» / «В повторение» / «Подробнее» |
| RetryCapture | Подсказка «повторите съёмку» при низкой уверенности распознавания (состояние поверх Camera/RecognitionResult) |
| SignDetail | Подробности о знаке или дорожной ситуации: штрафы и расширенное описание — открывается по кнопке «Подробнее» |
| History | История последних 5 сканов |
| ReviewQueue | Очередь повторения — вопросы из тестов и сканы, добавленные через «В повторение» |
| PrivacyBadge | Бейдж/сообщение «Обработка на устройстве» при первом использовании камеры (не отдельный экран — оверлей поверх Camera) |

## Экраны следующих версий (упомянуты в Roadmap, вне MVP)

| Имя (лат.) | Что происходит | Версия по PRD |
|---|---|---|
| AccidentMode | Базовый режим аварии — шаги, что делать при ДТП | v1.1 |
| Paywall | Экран апгрейда до Премиум | v1.1 (см. открытый вопрос про конфликт с KPI ниже) |
| VideoAnalysis | Видео-анализ / премиум-разборы situaций | v2.0 |
| InstructorDashboard | Дашборд для инструкторов автошколы — аналитика по ученикам | v2.0 |
| Progress | Профиль/прогресс с продвинутой геймификацией (бейджи, уровни) | v2.0 |
| ARMode | AR-подсказки поверх камеры (после юридической проверки) | v2.0 |

Виджет/wake-word из раздела «Что НЕ входит» — не включаю как экран: это системный виджет вне навигации приложения, а не отдельный экран/узел sitemap.

## Отсутствуют в PRD, но без них продукт не соберётся

| Имя (лат.) | Что происходит |
|---|---|
| Permissions | Запрос доступа к камере и микрофону — обязателен для camera-first флоу, в PRD не упомянут |
| Settings | Базовые настройки: выключить звук/TTS (PRD упоминает возможность отключить звук, но не даёт этому экрана), версия базы знаков, о приложении |
| Loading | Состояние загрузки/ожидания — например, если распознавание идёт дольше обычного, синхронизация локальной базы знаков |
| EmptyState | Пустые состояния — пустая история сканов, пустая очередь повторения |
| Error | Общая ошибка — сбой распознавания, нет доступа к камере, повреждённая локальная база |
| NotFound | Заглушка на некорректный/устаревший deep link (менее критично для мобильного приложения, чем для веба, но включаю для полноты) |

## Открытые вопросы, всплывшие при инвентаризации

- **Paywall vs KPI**: PRD ставит KPI «Конверсия Free→Premium ≥5% к 3-му месяцу» в разделе OKR (для MVP), но сам экран Paywall/монетизация назначен в Roadmap только на v1.1. Непонятно, должен ли Paywall быть в MVP хотя бы в базовом виде, чтобы KPI было к чему измерять. Нужно уточнить у PM.
