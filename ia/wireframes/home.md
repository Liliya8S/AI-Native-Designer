# Home

**Размер:** mobile 375×812
**Назначение:** главный экран с CTA «Начать тест» / «Камера» / «История»

## Секции (сверху вниз)

### Header (56px высота)
- Название приложения (левый край): «ПДД Ассистент»
- Иконка Settings (правый край, 24×24)

### HeroCTA — Camera (176px высота)
- Плейсхолдер-иконка камеры по центру (64×64)
- Крупная кнопка на всю ширину: «Открыть камеру»
- Подпись под кнопкой: «Распознать знак за 3 секунды»

### SecondaryCTA — Tests (96px высота)
- Кнопка на всю ширину: «Начать тест»
- Подпись под кнопкой: «Билеты ПДД, офлайн»

### ReviewQueueTeaser (карточка, 72px высота)
- Заголовок: «В повторении: 4 темы»
- Ссылка справа: «Продолжить →»

### RecentScans (список из 3 карточек)
- Превью-плейсхолдер 48×48
- Название знака (например, «Уступите дорогу»)
- Дата скана (например, «Сегодня, 14:20»)

## Пустое состояние
RecentScans, если сканов ещё нет: иллюстрация-плейсхолдер 96×96 по центру + текст «Пока нет сканов» + подпись «Наведите камеру на знак, чтобы начать»

### TabBar (56px высота, зафиксирован снизу)
- Home (active)
- Tests
- Camera (акцентная, по центру, крупнее остальных вкладок)
- History
