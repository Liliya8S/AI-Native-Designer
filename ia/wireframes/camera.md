# Camera

**Размер:** mobile 375×812
**Назначение:** экран камеры для распознавания знака

## Секции (сверху вниз)

### Header (56px высота, поверх видоискателя)
- Иконка «Назад» (левый край, 24×24)
- Иконка вспышки (правый край, 24×24)

### Viewfinder (Main, ~580px высота)
- Плейсхолдер-прямоугольник на всю ширину — живой превью камеры
- Рамка-гид по центру (пунктирный квадрат 240×240) с подписью под ней: «Наведите на знак»

### PrivacyBadge (оверлей, показывается один раз при первом использовании)
- Плашка сверху видоискателя (под Header): иконка замка + текст «Обработка на устройстве» + крестик закрыть

### CaptureBar (76px высота, зафиксирован снизу)
- Превью последнего скана (миниатюра-плейсхолдер 40×40, левый край) — быстрый переход в History
- Кнопка съёмки (крупный круг 72×72, по центру)
- Заглушка справа (40×40, зарезервировано под будущий toggle режима, сейчас пусто)

## Состояние Loading
Пока идёт распознавание (до 3 секунд): поверх Viewfinder — затемнение + спиннер-плейсхолдер по центру + текст «Распознаём...». Кнопка съёмки неактивна.

## Состояние RetryCapture (низкая уверенность)
Плашка снизу, над CaptureBar: текст «Не удалось распознать чётко. Повторите съёмку» на жёлтом плейсхолдере. Кнопка съёмки остаётся активной.

## Состояние Error (нет доступа к камере)
Viewfinder заменяется на: иконка-плейсхолдер камеры перечёркнутой (64×64) по центру + текст «Нет доступа к камере» + кнопка «Открыть настройки»
