# RecognitionResult

**Размер:** mobile 375×812
**Назначение:** карточка результата распознавания — сводка, индикатор уверенности, действия

## Секции (сверху вниз)

### Header (56px высота)
- Иконка «Закрыть» ✕ (левый край, 24×24) — возврат на Camera

### PhotoPreview (320px высота)
- Плейсхолдер-фото сделанного снимка знака, на всю ширину

### ConfidenceBadge (32px высота, наложена на нижний левый угол PhotoPreview)
- Пилюля с текстом: «Уверенность: Высокая» (High / Medium / Low)

### SummaryCard (Main, ~180px высота)
- Иконка динамика (правый верхний угол карточки, 20×20) — идёт автоматическая озвучка
- Заголовок (H2): «Уступите дорогу»
- Текст сводки, 1–2 предложения: «Вы обязаны уступить дорогу транспортным средствам, движущимся по главной дороге»

### ActionsRow (64px высота, зафиксирован снизу)
- Кнопка «Переснять» (outline, треть ширины) — соответствует «Повторить» из критериев приёмки PRD (пересъёмка знака)
- Кнопка «Повторить» (primary, треть ширины) — соответствует «В повторение» из критериев приёмки PRD (добавить тему в очередь повторения)
- Ссылка «Подробнее →» (text, треть ширины) — ведёт на SignDetail

## Примечание
Три действия из критериев приёмки PRD сохранены, но два из них переименованы в UI, чтобы не звучать как дубли: «Повторить»→«Переснять», «В повторение»→«Повторить». Функция и core-метрика («нажали В повторение хотя бы раз») не меняются — переименован только лейбл на экране. Отдельной кнопки «Сохранить» нет — каждый скан автоматически попадает в History (последние 5), явное сохранение не требуется.
